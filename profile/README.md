Container images of the [Exim](https://www.exim.org/) mail transfer agent, built from the upstream release tags on Debian 13, for amd64 and arm64. A new Exim release or a Debian security update publishes a new image on its own.

| Repository | Content |
|---|---|
| [exim](https://github.com/exim-container/exim) | the image, published as `ghcr.io/exim-container/exim` |

```sh
docker pull ghcr.io/exim-container/exim:4
```
